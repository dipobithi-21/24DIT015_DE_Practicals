# Data Quality Summary

## Objective
To validate and profile customer data before storing it into the database.

## Validation Performed

- Generated synthetic customer dataset using Faker
- Read CSV, JSON and configuration files
- Profiled dataset
- Checked missing values
- Checked duplicate records
- Stored validated data into SQLite
- Generated data quality log
- Validated incoming files

## Result

The dataset passed all validation checks successfully and was stored in the SQLite database.
